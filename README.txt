# Tamira's BIG Question?

A tiny single-use pixel-art love-game website.

## Run it
Open `index.html` in a browser.

No server or installation is required.

## Flow
1. Start screen
2. Character selection — S. Egshiglen
3. Question — "Would you like to try us again? — Tamir."
4. YES triggers pixel confetti and the "DM ME" ending
5. NO playfully moves away

## Easy customization
Open `index.html` to change the text.

Open `style.css` to change the colors, fonts, sizes, and visual style.

Open `script.js` to change the interactions and confetti.
